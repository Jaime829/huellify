# Huellify

Huellify es un plataforma que te permite seguir tu huella de carbono personal y te da recomendaciones de como mejorar tu impacto ambiental:

## Características principales

- Autenticacion de usuarios
- Calculo aproximado de huella de carbono
- Recomendaciones generales

## Tecnologías utilizadas

- **Frontend:** Blade, Interia.js,React, TailwindCSS
- **Backend:** Laravel
- **Base de datos:** PostgreSQL

## Prerrequisitos e instalación

Instrucciones paso a paso para clonar y ejecutar el proyecto localmente:

1. Clona el repositorio:
   \`\`\`bash
   git clone https://github.com/tu-usuario/tu-repositorio.git
   \`\`\`

2. Instala las dependencias:
   \`\`\`bash

    npm install
    composer install

    \`\`\`

3. Configura tus variables de entorno:
    - Duplica el archivo `.env.example` y renómbralo a `.env`.
    - Completa los datos de conexión a tu base de datos.

4. Ejecuta el servidor de desarrollo:
   \`\`\`bash
   composer run dev
   \`\`\`
